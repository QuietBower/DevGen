# Linux kernel code analysis tool

A C/C++ code analysis tool based on the Clang LibTooling framework, used to extract various declaration information from the Linux kernel source code.

## Compile

After installing clang-15, execute the following command to generate the executable file `analyze`:

```bash
make analyze
```

## Use

Execute in the Linux directory:

```bash
./path/to/analyze -p compile_commands.json
```

## Input

The Linux kernel compiled under clang-15, with the `compile_commands.json` compilation database file generated by the bear tool.

## Output

Under the Linux directory, various code definition files (in JSONL format, with one JSON object per line) are generated:

| File                   | Content                   |
| ---------------------- | ------------------------- |
| `define.jsonl`         | macro definition          |
| `enum.jsonl`           | enumeration definition    |
| `enum-typedef.jsonl`   | enumeration typedef       |
| `func.jsonl`           | function definition       |
| `struct.jsonl`         | structure definition      |
| `struct-typedef.jsonl` | structure type definition |
| `struct-init.jsonl`    | struct initialization     |
| `var.jsonl`            | variable declaration      |

## Workflow

The workflow of the **analyze** tool is as follows:

```
Load compile_commands.json
        │
        ▼
┌────────────────────────────────────────────────────────────────────┐
│  Create a thread pool (with a maximum of 40 concurrent threads)    │
└────────────────────────────────────────────────────────────────────┘
        │
        ▼
Read the source file path
        │
        ▼
Locate the source file based on the file path
        │
        ▼
Use the Clang AST tool to expand the source file into an AST (Abstract Syntax Tree)
        │
        ▼
Call the corresponding callback function for each node in the AST:
  ├── VisitFunctionDecl()    → func.jsonl
  ├── VisitRecordDecl()      → struct.jsonl
  ├── VisitEnumDecl()        → enum.jsonl
  ├── VisitTypedefDecl()      → typedef.jsonl / enum-typedef.jsonl / struct-typedef.jsonl
  ├── VisitVarDecl()          → var.jsonl / struct-init.jsonl
  └── MacroDefined()         → define.jsonl
        │
        ▼
Write the collected definitions into the corresponding jsonl files.
```
