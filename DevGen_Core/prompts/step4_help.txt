    system_ss.add(when: 'CONFIG_`DRIVER_NAME (all uppercase)`_PCI', if_true: files('`DRIVER_NAME`_pci.c'))

2. Copy start_qemu_old.sh to start_qemu.sh, and replace `DRIVER_NAME` in the content of start_qemu.sh with the name of the program currently being processed.

## Note: at this point DRIVER_NAME should have all "-" changed to "_"

3. Copy (or overwrite) the generated QEMU .c result into hw/fake_pci.

4. Run the build.sh script and then start_qemu.sh.

5. Use Python to open a new terminal and execute the command:
    ssh -i /home/wmy/Fuzzer/third_tool/Image-defconfig/bullseye.id_r                                                            sa root@127.0.0.1 -p 10021

6. Create four directories in the project: out/share, out/shares, out/shares/success, and out/shares/fail, and run the command:
    mount -t 9p -o trans=virtio,version=9p2000.L hostshare /mnt

7. Run the following commands respectively:
    1. lspci -k -s 00:04.0 > /mnt/load.txt
    2. tree /dev > /mnt/dev.txt

8. Search load.txt for the field "Kernel driver in use". If it exists, skip this step; if not, run the following commands:
    1. dmesg -C
    2. modprobe "driver_name"
       modprobe -r "driver_name"
       modprobe "driver_name"
       echo 0000:00:04.0 > /sys/bus/pci/drivers_probe
    3. dmesg >> /mnt/err_msg.txt
    4. init 0

9. If "Kernel driver in use" appears, create a folder named after the driver under out/shares/success, copy all results from step 7 into that folder, and jump directly to the final step.
   If it does not appear, continue execution.
   Make a copy of the VM.

## Note: this stage covers the case where "Kernel driver in use" does not appear, i.e., the step4 flow is invoked.

    Iterate through all the repair result information compiled by Wang Zhi, and find two examples to pass in for analysis.

11. Go back to step 3 and execute it again.

## The above iteration runs three times; after asking three times, stop asking and force the next step.

12. If it has never been repaired successfully, likewise create a folder named after the driver under out/shares/fail and copy all results from steps 7 and 8 into that folder.
